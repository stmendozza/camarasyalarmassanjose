## Reglas de asignación

1. Cada término **head** tiene **una** URL primaria.
2. Variaciones long-tail viven como H2/FAQ/bloques en esa URL (no páginas vacías).
3. Todas las titles incluyen geolocalización cuando la intención es local.
4. `/hogar` y `/negocios` atacan modificadores de audiencia, no el head term solo.
